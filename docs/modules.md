# Data modules (draft)

The dataset will be organised into modules by domain, each a flat township-year panel. Modules merge on the Core Keys. Module contents, variable lists and dates below are plans and may change before release.

| Module | Planned variables | Description | Planned |
|---|---|---|---|
| Core Keys | miracle_id · province · municipality · township · concordances | Geographic identifiers and boundary concordances across the 1963/1973 reorganisations. | 2026 (pilot) |
| Demographics | population · households · age structure | Population counts, household numbers, demographic composition. | 2026 (pilot) |
| Agriculture | paddy area · crop output · livestock | Cultivated area, output (harmonised to metric units), livestock. | 2026 (pilot) |
| Industry | establishments · employment · output | Industrial establishments, manufacturing employment, sectoral output. | 2028 |
| Infrastructure | roads · electricity · water · telecom | Road length, electrification, public utilities. | 2028 |
| Public Finance | revenues · expenditures · transfers | Municipal revenue/expenditure, central transfers, fiscal capacity. | 2028 |
| Education | schools · enrolment · teachers | School counts, enrolment, teachers, educational infrastructure. | 2028 |
| Geospatial | shapefiles · centroids · boundaries | GIS boundary files with consistent township geometries. | 2028 |
| Institutions | clan concentration · bureaucratic capacity | Pre-treatment institutional measures from 1930 registries and personnel files. | 2029 |

The pilot release covers about 400 townships along the Gyeongbu Expressway corridor. Variable definitions and coverage for each module will be documented here as modules are released.
